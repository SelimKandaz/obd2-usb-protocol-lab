# captures/

This directory is intentionally **empty in Git**. Real captures may contain
other USB devices' traffic and host-identifying data, so:

- Raw captures live in `private_samples/captures/` (git-ignored).
- Only small, **redacted**, **synthetic** captures may ever be committed, and
  even those are normally generated by the test-suite in memory rather than
  stored here.

`.gitignore` ignores `captures/*` except this README.
