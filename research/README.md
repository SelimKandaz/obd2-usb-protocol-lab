# research/

Working notes and the evidence log. Keep raw thinking here; promote confirmed
facts into `docs/` and `reports/` with confidence tags.

## Rules
- Every note records: source, date, tool version, file/capture hash, the exact
  observation, the hypothesis, a confidence tag, and reproduction steps.
- Confidence tags: `VERIFIED · HIGH · MEDIUM · LOW · UNKNOWN`.
- Never assert "the protocol does X" without ≥2 independent sources.
- No proprietary bytes, host paths, or usernames in committed notes.

Use `NOTES_TEMPLATE.md` for each new investigation.
